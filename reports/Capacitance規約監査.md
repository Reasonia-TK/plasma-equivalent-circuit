# シース容量規約 `alpha_C` の監査

作成日: 2026-09-02  
対象: Schmidt, Mussenbrock, Trieschmann (2018), [arXiv full text](https://arxiv.org/html/1804.05638v1)

## 結論

標準再現で用いた `alpha_C=0.5862` は、行列シースから第一原理的に得られる係数ではなく、論文の公開標準点を再現するための経験的な実効微分容量係数である。

- 一様イオン密度の行列シースから導く物理的な微分容量は、論文記載式のちょうど半分、すなわち `alpha_C=0.5` になる。
- ngspice 27および28のソースを調べると、電圧依存容量 `C={式}` は `I=C(V)dV/dt` として処理されていた。旧版と現行版の容量規約差では `0.5862` を説明できない。
- `alpha_C=0.5` で計算した負荷を基本波で再整合すると、必要容量は `C_m1=1544.1 pF`、`C_m2=176.9 pF` であり、論文の丸め値 `1550 pF`、`175 pF` に近い。
- しかし `alpha_C=0.5` のままグローバルモデルと整合器を自己無撞着に反復すると、`n_e=9.55e14 m^-3`、`P_pl=3.71 W` となり、論文値 `1.25e15 m^-3`、約`5 W`を再現しない。

したがって、論文の丸められた整合容量だけを根拠に `alpha_C=0.5862` を物理定数と解釈してはならない。本リポジトリでは名称を `published-point-calibrated-differential` とし、標準点の再現と範囲外予測を区別する。

## 1. 行列シースからの導出

一様なイオン密度 `n`、面積 `A`、シース厚さ `s` に対して、Poisson方程式から

```text
V_s = e n s^2 / (2 epsilon_0)
Q_s = e n A s
```

となる。`s` を消去し、`K=2 e n epsilon_0 A^2` とおけば、

```text
Q_s(V_s) = sqrt(K V_s)
Q_s / V_s = sqrt(K / V_s)
dQ_s / dV_s = 0.5 sqrt(K / V_s)
```

を得る。論文の式(2)、(3)は `dV_s/dt=C_s^-1 I` の形なので、回路方程式へ入る量は微分容量 `dQ_s/dV_s` である。一方、論文本文に記載された `C_s=sqrt(K/V_s)` は割線容量 `Q_s/V_s` と一致し、物理的な微分容量の2倍である。

この係数2の区別を単体試験へ追加し、`Q_s` の数値微分が `0.5 sqrt(K/V_s)` と一致することを検証した。

## 2. ngspice実装規約の確認

著者netlistと補足コードは公開検索で確認できなかった。そのため、論文公開時期に近い公式ngspiceソースのタグを確認した。

| 版 | 公式タグのコミット | `C={式}` の意味 |
|---|---|---|
| ngspice-27 | `af7ab797c2b5548a99d9bcb4c7f74556aa4ac67e` | `I=C(V)dV/dt` |
| ngspice-28 | `38ed802ba44bb42c4744e8b838e30f84b97bef08` | `I=C(V)dV/dt` |

当時の入力変換処理は、単位容量を電圧制御源で駆動し、返還電流を `i(E)*equation` とする。したがって、式を電荷として積分するのではなく、指定値を微分容量として使う挙動である。現行ngspice-46に対する既存の電圧ランプ試験とも整合する。

## 3. 固定密度での容量規約感度

論文密度と論文の整合素子を固定し、容量係数だけを変えた結果を示す。解析整合容量は、各ケースの基本波負荷インピーダンスから同じL型回路トポロジーで逆算した。

| `alpha_C` | `Z_load` (ohm) | 論文容量での `Z_in` (ohm) | 解析 `C_m1` (pF) | 解析 `C_m2` (pF) | `P_pl` (W) |
|---:|---:|---:|---:|---:|---:|
| `0.5` | `1.129-j54.029` | `32.32+j17.01` | `1544.12` | `176.92` | `4.06` |
| `0.5862` | `1.126-j53.35` | `49.67-j0.02` | `1544.30` | `175.12` | `4.73` |
| `1.0` | `1.77-j44.97` | `1.44-j14.22` | `1224.07` | `159.51` | `1.41` |

`alpha_C=0.5` の解析整合容量が論文値に近いことから、論文掲載値の丸めと高Q回路の感度が、`alpha_C=0.5862` の一点同定を強く左右した可能性がある。ただし、これは推論であり、著者netlistなしには確定できない。

## 4. `alpha_C=0.5` の完全連成・再整合

容量係数を物理的微分容量の `0.5` に固定し、密度反復と基本波整合を交互に実行した。

| 量 | 結果 | 論文値・目安 |
|---|---:|---:|
| `T_e` | `4.7493 eV` | `4.75 eV` |
| `n_e` | `9.5526e14 m^-3` | `1.25e15 m^-3` |
| `C_m1` | `1565.77 pF` | `1550 pF` |
| `C_m2` | `178.39 pF` | `175 pF` |
| `Z_in` | `50.22-j0.63 ohm` | `50.01-j0.02 ohm` |
| `P_pl` | `3.708 W` | 約`5 W` |
| `V_pl` 振幅 / DC | `369.0 / -256.1 V` | 約`360 / -250 V` |
| `I_pl` 基本波 | `0.460 A` | 約`0.6 A` |

密度反復は収束し、電力収支残差は `0.0288%` だった。整合器外反復は設定した12回では厳密閾値へ届かなかったが、入力インピーダンスと容量値は論文近傍に到達している。それでも密度、プラズマ電流、吸収電力の差が残るため、容量規約だけでは公開結果全体の差を説明できない。

## 5. 採用方針

1. Schmidt標準点の再現では `alpha_C=0.5862` を維持し、経験的校正値であることを設定とレポートへ明記する。
2. 範囲外予測では係数を再調整せず、同じ `0.5862` を固定する。
3. 装置データと比較する際は、`alpha_C=0.5` と `0.5862` をモデル不確かさの2ケースとして扱う。
4. 著者netlistまたは実験的なシース電荷―電圧関係が得られた場合のみ、容量規約を更新する。

数値の機械可読データは [schmidt2018_validation.json](data/schmidt2018_validation.json) に保存した。
